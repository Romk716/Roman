## Шаблон тест-кейса

- **Идентификатор:** TC-XX
- **Название:** Краткое описание проверки
- **Связь с требованиями:** R-XX
- **Связь со сценариями:** S-XX
- **Предусловия:** Что должно быть выполнено до начала теста
- **Входные данные:** Конкретные значения, которые будут использоваться
- **Шаги:** Нумерованный список действий
- **Ожидаемый результат:** Что должно произойти после выполнения шагов
- **Постусловия:** (если нужно) Действия для восстановления исходного состояния
- **Важность:** BLOCK / WARN

## Набор данных для тестирования

- **Задача A (короткая):**  
  - Название: `Smoke`  
  - Описание: `Быстрая проверка`

- **Задача B (длинная):**  
  - Название: `Отчёт по практике`  
  - Описание: `Подготовить развёрнутый отчёт о проделанной работе за первый семестр, включая графики и таблицы.`

- **Задача C (смешанный регистр):**  
  - Название: `PyTest Case`  
  - Описание: `Пример для проверки регистронезависимого поиска`

- **Ошибочный ввод D (пустое название):**  
  - Название: `""` (пустая строка)  
  - Описание: `Любое описание`

- **Ошибочный ввод E (недопустимый статус):**  
  - Статус: `отложено` (не в списке допустимых)

## TC-01: Создание задачи с валидными данными (счастливый путь)
Связь с требованиями: R-01

Связь со сценариями: S-01

Предусловия:

Файл tasks.json отсутствует или пуст.

Программа запущена в терминале с активированным окружением.

Входные данные: Задача A (название Smoke, описание Быстрая проверка).

Шаги:

Ввести команду создания задачи с указанными данными (например, add "Smoke" "Быстрая проверка").
Ввести команду просмотра списка (list).
Ожидаемый результат:

В списке отображается задача с названием Smoke, описанием Быстрая проверка, статусом по умолчанию (новая) и уникальным идентификатором (число).

Файл tasks.json создан и содержит корректную JSON-запись о задаче.

Важность: BLOCK

## TC-03: Изменение статуса задачи на допустимый
Связь с требованиями: R-03

Связь со сценариями: S-03

Предусловия:

## TC-05: Поиск по ключевому слову (регистронезависимость)
Связь с требованиями: R-04

Связь со сценариями: S-04

Важность: WARN
